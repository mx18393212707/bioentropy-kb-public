# 08-每日整理 · 说明

本文件夹存放**每日整理智能体**（WorkBuddy 技能 `bioentropy-daily-organize`）的自动产出，每日 21:30 运行一次（也可随时对 AI 说"整理今天的资料"手动触发）。

## 每日整理报告能帮你什么

- **今日新增/变更清单**：昨天以来知识库里多了什么、动了什么，一张表看完
- **Clippings 归位记录**：Edge Web Clipper 剪藏的网页自动归类到主题文件夹（from → to 可追溯）
- **HiNote 批注深挖**：你在 Obsidian 里用 HiNote 做的高亮批注，智能体会读取并按你的批注意图检索补充文献、给出深挖建议
- **待人工决策**：智能体不确定的归类、值得精读的新文献，列出等你拍板
- **今日一句话**：跨笔记联想，把新内容与既有笔记串起来

## 约定

- 智能体**不删除任何文件**、不改你手写的正文，只做：移动位置、补 frontmatter、文末追加"AI 整理记录"
- 阅读状态（已精读/泛读/待读）永远由你人工改动
- 报告本身按日期归档在本文件夹，月度由索引维护技能清理归并
