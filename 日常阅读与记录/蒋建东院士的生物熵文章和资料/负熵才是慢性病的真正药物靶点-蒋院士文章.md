# 对启发查证

## 不应盲目纳入AMPK所有通路

你问：AMPK是能量代谢关键分子，是否要在ODE建模中纳入AMPK相关所有代谢通路？

答案是：**不要。**

如果把AMPK所有通路都纳入，模型会迅速失控，节点太多、边太多、参数太不确定，毕设无法完成。

你应该只纳入和“T2DM脂肪组织巨噬细胞负熵恢复”直接相关的 AMPK 下游模块：

|AMPK相关方向|是否纳入|原因|
|---|---|---|
|AMPK → SIRT1/PGC-1α → mitochondrial biogenesis|必纳入|连接能量稳态与线粒体负熵|
|AMPK → NF-κB/NLRP3 抑制|必纳入|连接能量状态与巨噬细胞炎症|
|AMPK → ACC/CPT1 → fatty acid oxidation|建议纳入|连接脂毒性和脂肪酸氧化|
|AMPK → insulin sensitivity / GLUT4|建议纳入|连接T2DM表型|
|AMPK → mTOR/autophagy|可选|有意义，但可放拓展|
|AMPK全部下游代谢网络|不建议|超出毕设规模|

也就是说，你不是建“AMPK百科模型”，而是建：

**AMPK作为HGM候选时，是否能通过有限代表性通路启动脂肪组织巨噬细胞系统的负熵恢复。**

## GLP-1R能否纳入模型？

可以，但要谨慎定位。

GLP-1R 是非常有潜力的 HGM-like 候选，因为 GLP-1R 药物已经在T2DM、肥胖和心血管代谢疾病中显示出强临床效应。GLP-1R明确存在于胰岛和中枢神经系统，也存在于部分外周组织；但在脂肪组织中的直接表达和作用仍有争议。近年综述指出，白色脂肪组织中GLP-1R表达较低，bulk WAT检测到的GLP-1R可能来自非脂肪细胞成分，如基质血管组分、单核细胞或免疫细胞，而不是成熟脂肪细胞本身。

但它与巨噬细胞有关系。有研究使用 GLP-1R-EGFP 转基因小鼠确认巨噬细胞中存在 GLP-1R，且M2型和Ly6C⁺巨噬细胞表达更高；GLP-1R缺失会降低巨噬细胞迁移并增强IL-6表达。 另有体外研究显示 GLP-1 可通过GLP-1R/STAT3方向促进人单核来源巨噬细胞向M2样表型转化，并增加脂肪细胞 adiponectin 分泌。

所以在你的模型中，GLP-1R可以纳入，但建议这样处理：

**不要把GLP-1R作为脂肪细胞强表达节点。**

而应作为：

> **系统性代谢治疗受体 / 巨噬细胞免疫调节候选HGM / 外周-中枢-胰岛-脂肪组织交互接口节点。**

第一版模型可以这样写：

GLP1R→STAT3/IL10/M2
GLP1R⊣IL6
GLP1R→insulin sensitivity

但你需要在论文中注明：**GLP-1R在脂肪组织中的直接作用存在争议，因此其在模型中作为候选HGM而非确定HGM。**












# 概念理解

## 1. 头雁分子：只有极少数细胞蛋白能够重新编程其信号网络以阻止疾病进展，本文中称之为头雁分子（HGMs）


头雁分子 HGM： 不是一般关键节点，也不是药物、营养物质、刺激源或表型节点，而是能够启动负熵机制、重编程病理网络、使系统从失序走向有序的少数核心蛋白或分子调控者。

- 据估计，哺乳动物细胞每个细胞含有数万多个蛋白质。大多数蛋白质或其修饰（如糖基化、磷酸化、甲基化和乙酰化的蛋白质）作为信号通路网络中的单一节点，具有多种细胞功能，且通常可互换或可替代。
- 原则上，只有少数细胞内蛋白能够作为关键的先驱者，在重编程细胞网络、有效暂停或逆转疾病进展方面发挥作用。
	- 通过药物干预调节这些蛋白质，可能**引发整个网络的连锁反应**（_例如_，_g_.，腺苷5′-单磷酸（AMP）激活蛋白激酶**AMPK**，用于能量代谢）。这种生物现象可以被描述为“**头雁效应（HGE**）”
- **大雁的类比**：在野雁季节性迁徙期间，鹅群要么向南或向北，高度协调，通常呈“V”或“—”形飞行，由一只强壮、聪明且经验丰富的鹅领头[](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib28) [28,29](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib29)。领头鹅的翼翼带来的空气动力学优势帮助后方的鹅以节能模式飞行，使它们能够高效地飞行数千公里（[30](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib30)， [31](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib31)， [32](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib32)）。当领头的鹅感到疲惫时，另一只能干的鹅会接替[领导位置。](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib29)





# 关于头雁分子AMPK 的药物设计：直接作用的药物失败

- 已有充分文献证明AMPK磷酸化和激活调控多条下游信号通路，因此可以视为维持能量代谢稳态的HGM39,40。
- 事实上，**间接靶向AMPK的药物**，如**二甲双胍**和**黄连素（BBR）**，已在降低血糖或血脂、抗炎以及预防癌症和心血管事件方面展现出临床疗效[](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib41) 41,42[](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib42)。
- 然而，设计中与**AMPK直接相互作用强烈的化合物在临床试验中[失败**，这](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib43)让我们有更多空间思考基于AMPK的药物设计

# 小檗碱（BBR）作为头雁探索的多靶点药物

- 如果使用传统生物技术，从细胞蛋白库中识别HGM相当困难。因此，我们从另一个角度看待HGMs，并认为多功能（或多靶点）药物可能有助于探究HGMs。
- BBR是一种在代谢方面具有多种药物效应的药物
	- 临床上有效治疗或预防血脂异常、2型糖尿病（T2D）、脂肪肝以及心血管疾病（[50,55,56,57](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib50)[](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib55)） [](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib56)[](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib57).
	- BBR的机制与LDLR和胰岛素受体（InsR）的上调以及AMPK的激活、PCSK9的抑制[相关，但](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib60)主要靶点尚不明确。
	- 最新研究表明，BBR进入肝细胞线粒体，直接结合并激活Sirtuin 3（SIRT3），从而减少线粒体复合体I（CI）N模块催化亚基NDUFS1的乙酰化，最终导致线粒体CI[61](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib61)的解离。
		- 文献研究发现SIRT3与AMPK和PCSK9通路[62](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib62)、[63](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib63)、[64](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib64)相关。
		- 我们认为SIRT3（线粒体CI）可能是BBR的主要靶点，并且可能作为治疗代谢疾病的HGM。
		- 事实上，越来越多的证据表明**SIRT3**与多种人类疾病相关，如年龄相关疾病、心脏病、癌症和代谢疾病（[65](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib65)、[66](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib66)、[67](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib67)、[68](https://pmc.ncbi.nlm.nih.gov/articles/PMC12828147/#bib68)），支持SIRT3作为潜在的HGM。
