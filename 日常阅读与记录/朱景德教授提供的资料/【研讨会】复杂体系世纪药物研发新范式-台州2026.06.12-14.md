# 复杂体系世纪药物研发新范式研讨会 / 第 29 届集智同行动议研讨会

> **会议主旨**：从 20 世纪「单点还原论」跨越到 21 世纪「复杂系统理论」,**新药研发必须告别「一药一靶」线性思维,走向体系化、动态化、时空多尺度协同的新范式**。
> **金句锚点**：丹尼斯·诺贝尔(Denis Noble) —— *「我们在分子、细胞的微观世界里取得了无数近乎完美的胜利,但当这些成果试图跨越空间与时间的巨壑、走向宏观临床时,往往在一夜之间灰飞烟灭。这种「尺度错配」(Scale Mismatch)是二十一世纪医学面临的最大难关。」*

## 2. 复杂体系世纪新药研发新范式:核心思想

### 2.1 反摩尔定律(Eroom's Law)

> 自 1950 年起,每 10 亿美元研发投入所能产出的上市药物数量,平均每九年减半。
> 电子学摩尔定律:每 18-24 个月晶体管翻倍,成本减半。

**深层归因**:生命体系高维复杂性 — 非线性网络、反馈结构、表观调控、代谢重构、免疫微环境深度耦合,使「单靶点-单路径」范式全面失效;90% 惊艳实验室数据在临床二期宣告失败。

### 2.2 尺度错配的三种形态

| 维度 | 错配表现 | 解决方向 |
|---|---|---|
| **空间** | 体外二维细胞 vs 体内三维组织;局部靶点高亲和 ≠ 整体系统有效 | 引入 3D 类器官、空间多组学、原位力测量 |
| **机制** | 单一因果链条 vs 多通路负反馈与旁路激活 | 网络 × 能景 × 跨尺度动态机制图谱 |
| **时间** | 动物模型短期实验 vs 人体数十年病程;静态医学快照 vs 24h 昼夜节律 | 时间药理学、智能时程给药、时序单细胞组学 |

### 2.3 新范式的关键对仗(锐评版)

| 旧范式(20 世纪) | 新范式(复杂体系世纪) | 锐评 |
|---|---|---|
| 单靶点(one target → one drug) | 体系干预(组合 × 时序 × 患者状态 × 反馈) | 「把靶点当开关 = 二维脑图做高维问题」 |
| 通路图指导(linear pathway) | 网络 × 能景 × 跨尺度机制图谱 | 「只会画 pathway 的团队,找不到真正能改变病程的干预入口」 |
| HTS→lead→Ⅲ 期线性流水线 | 模型—实验—临床闭环(co-design loop) | 「AI+HTS = 更快地在错误假设空间搜索」 |
| 统计终点(ORR/HR/PFS) | 机制驱动 + 群体异质性动态终点 | 「p<0.05 掩盖了大量系统级信息」 |
| Ⅲ 期一次性大赌注 | 平台试验 + 适应设计 + RWD 学习系统 | 「仍按静态试验做复杂病 = 用算盘打量子」 |
| 早期只验有效/无效 | 结构化数据(力学/代谢/表观/时序)驱动反馈 | 「不收结构性数据的实验体系是哑巴实验室」 |
| 药物 = 单分子 | 多模干预(药 × 物理场 × 免疫 × 代谢) | 「只换更强的单模药 = 更快进入耐药 attractor」 |
| 监管:静态终点+一次审批 | 复杂体系监管科学:动态证据+滚动评估 | 「科学能做的,监管没准备好 → 新范式走不出」 |

### 2.4 集智同行动议「四阶」SOP(Every Second for Science)

1. **第一阶**:会前 4 个月建立微信群,深度论文预读 + 报告内容分享
2. **第二阶**:17 min 报告 + 3 min 答疑(严格守时,不讲海量数据,讲「可分享的知识/技术」+「面临的挑战」)
3. **第三阶**:**学术权重最高的全员讨论**(≥1.5 小时,主席主持,聚焦知行合一)
4. **第四阶**:会后 10 天内公示 150-200 页详实纪要(本次会议纪要 219 页)

## 4. 四个全员讨论议题(朱景德主席主持)

### 议题一:新药研发的新范式(p145–158)

**核心判断**:现行「单基因靶点主导」是 20 世纪单点还原论产物(卡尔·波普尔所谓「系统性过度简化的艺术」);90% 临床二期失败 = 尺度错配。

**与会者金句**:
- **徐安龙**(北京中医药大学校长):「**反向药理学**」(reverse pharmacology) — 把食源性/中药先验(已有大规模人用数据)作为开发起点。例:**二甲双胍源自传统牧草山羊豆**(Galega officinalis),先有临床事实,后阐明 AMPK 机制。FDA 已为「中医经典名方 + 几十年临床验证」开放中药一类新药直接申报通道。
- **丁克**:抗生素真的治病,其他基本都是「控制」;**表型筛选** 在 1997 年前是主流,因当时模型支撑不了机制研究而被放弃;**罗成的工作把表型筛选「搬到了人身上」**(食源性先验),解决了大痛点。
- **田瑞军**:三阶段 — **靶点发现**(蛋白质组学可遍历 2 万+蛋白 × 修饰异构体) → **靶点到药物筛选** → **临床耐药**(KRAS/Daraxonrasib/Cell 已报道)。
- **王杰**:新药研发 =「**fast try, fast fail**」,**「暗数据」**——失败案例的负样本 —— 是 AI 模型的巨大财富。
- **杨弋**:跨团队制度化合作机制欠缺,需**预建合作规则**(IP、归属、学生培养、日常管理)。

### 议题二:AI4S 与 AIDD 的必要性、内涵和挑战(p159–165)

**核心判断**:AI4S 不是提效工具,而是**范式结构性重构** — 从「象试错」到「造物闭环」(Creating to Understand)。

**伦理警示**:必须警惕「知识异化」——用「理解力」换「预测力」导致智力萎缩;AI 无意识设计超级毒剂等生物安全底线不容逾越。人类科学家要「被迫升级」为**科学愿景的「总导演」+ 高价值数据的「架构师」+ 跨学科系统的「串联者」**。

**Google I/O 2026 节点**:「科研专用 AI 智能体体系」 — 数百万文献生成高置信度假设 + ERA 技术把数月计算验证压缩至数分钟 + 深度整合全球基础数据库 = 克服尺度错配的「数字大脑」。

**与会者金句**:
- **陈红明**:AIDD 核心瓶颈是**数据获取成本**;未必须发展**自动化实验室**+**联邦学习**等数据共享机制。
- **陈顺兴**:大模型靠海量高质量数据,AIDD 恰恰相反;团队一边做 AI 一边建实验平台采数据。
- **陆文超**:药物研发 4 阶段史 — 锁钥小分子 → 单抗(PD-1/PD-L1) → mRNA → **AI4S**。临港实验室 = 国家战略科技力量,坚持**干湿结合闭环**(AI 预测 → 严格靶标确证 → 多重正交实验 → 才交药物化学团队)。
- **陈军宁**:AIDD 实际应用不理想 — CRO 型公司用通用模型,缺乏反馈调整;**自建平台** 才是解决路径。
- **周云龙**:企业比学术界更快(尤其多肽新药);学术界需深度挖掘新型肽设计方法 + 类器官适应症概念验证。

### 议题三:力学生物学视角的新药研发(p166–176)

**核心判断**:力学生物学(Mechanobiology)是 21 世纪复杂体系生命医学**不可或缺**的关键视角。
- 21 世纪生命医学本质 = **细胞在力学场中的行为学**
- 五元联动:**能量 + 化学 + 机械力 + 结构 + 功能**,在多尺度时空持续耦合
- 三元耦合:**化学 + 力学 + 生物学**(2021 诺奖 PIEZO 已背书)
- **核心挑战四矩阵**:理论因果(力-化耦合)、实验技术(2D→3D 仿生 + 光成像 + 原位加力)、计算效率(多尺度软组织模拟)、临床转化(机械药理学 + 中医针灸现代力学证据)

**与会者金句**:
- **徐安龙**:针灸 = 明确的机械刺激过程 — 针刺为何引发远端生理效应(足三里→胃肠),缺少系统机制阐释。
- **朱奎**:呼吸道/消化道持续机械运动如何影响病原体侵入、宿主免疫响应及修复 — 非常值得研究。
- **王方军**:质谱多维成像(数百-上千分子同时)与力学/AI 数据分析的整合。
- **王杰**:广义「力学」=声光电力热,本质是相互作用;机械作用和电磁作用最终纳入多尺度物理框架。
- **姜洪源**:3D 打印 ≠ 功能实现(缺少微环境);**自下而上构建类器官** + 关注**功能涌现**(细胞集群的新行为)。
- **孙龙杰**:精子发生 = 流体力学;肿瘤转移的力学生物学被严重忽略。
- **张锋铭**:思维链 + **Harness Engineering**(多智能体协作网络) = 自闭环进化的 AI 工程体系。
- **王平**(台州药企代表):产学研脱节严重 — 科研国家队前沿理论与地方药企产业基础脱节;建议**下沉聚焦民生刚需**(食疗、中药有效成分挖掘、机理标准化)。

### 议题四:昼夜节律视角的新药研发和老药智用(p177–184)

**核心判断**:昼夜节律 = 「复杂体系世纪」新药研发必须夺回的**时间失地**。

**三大盲区**:
1. **静态医学**对时间维度的盲区 — 动态交响简化为静态快照,临床药效评估失真
2. **传统学科架构的尺度错配** — 基础/临床/信息数学高墙,缺乏真正以临床需求为导向的跨学科深度融合
3. **时间药理学的严重缺位** — 在错误节律相位盲目给药,人为放大毒性,错失顺时施治窗口

**新范式飞跃**:**从「顺应生物钟」到「工程化重建与重塑靶向节律」**。PD-1 抑制剂实证:肿瘤会主动粉碎内部时间秩序,制造「节律去同步化」,证实忽视时间结构的局限性。

**与会者金句**:
- **许代超**:生命本质依赖**振荡** — 清醒高能耗+ROS 暴增 → 睡眠低能耗+修复;**敲除细胞死亡关键基因可完全逆转睡眠剥夺致死表型**(实验室遗传学证据)。
- **罗成**:跳出单一靶点/单一机制思维 — 候选药物对机体整体的改善,尤其睡眠过程更平稳、效率更高、ROS 清除增强。
- **姜洪源**:夜间躺卧的力学刺激与白天活动差异 → 围绕力学差异开研究。

## 5. 导师刘振明报告要点(p92–95, p185–189)

> **报告题目**:新技术驱动的生物医药研究新范式思考与实践 — 北京大学智慧药物研发技术平台建设为例
> **背景**:北京大学药学院研究员/博导,中国化学会计算化学专委会委员;近五年第一/通讯 Nat. Mach. Intell.、Signal Transduct. Target. Ther.、J. Hematol. Oncol. 等 70+ 篇;CMNPD 海洋天然产物数据库(NAR 2020);XOR 抑制剂(Eur J Med Chem 2026)、ROR1 抑制剂(J Med Chem 2025)等。

### 5.1 核心观点(报告正文 + 闭幕总结)

- **AI 赋能不是叠加算法工具,而是系统性变革**:知识发现 + 实验验证 + 研发组织 + 临床转化逻辑的重构;**新药研发的根本目标未变**(安全、有效、质量可控),**变化的是「提出问题/组织资源/验证价值」的方式**。
- **AI 价值的本质**:不是「更快筛选更多分子」,而是**提升认知与决策能力** — 整合多组学 + 结构生物学 + 化学空间 + 药效 + 临床表型 + 文献,捕捉人类经验难直接捕捉的规律。
- **从「模型驱动」→「问题驱动」→「闭环驱动」**:AI 应贯穿 靶点发现 → 分子设计 → 合成路线 → 活性筛选 → 药效评价 → 临床研究,并被实验结果反向修正。
- **智慧平台四智能**:智能设计 + 智能合成 + 智能筛选 + 智能检测 → **数据贯通 + 反馈循环** = **持续学习、自进化的研发系统**(不是技术拼盘)。
- **数据是底层生产要素**:多源异构、噪声高、负样本不足、跨平台不可比 — **建设面向药物研发的数据基础设施是战略支点**(不是简单信息汇总)。
- **「预测」≠「验证」**:硅基预测不能替代生命体系真实验证;**评价标准必须落到真实研发指标**(命中率、迭代周期、无效试错、综合质量、临床转化概率)。
- **真正的竞争**:不再是单一模型/单一靶点/单一技术,而是**数据资源 + 算法模型 + 自动化实验 + 临床资源 + 组织协同能力**的系统竞争。

### 5.2 补充观点(闭幕总结 — p185–189 全文最精华段落)

1. **从临床需求出发**,不从算法炫示出发
2. **进入研发决策链**,不只停留在计算辅助(应能回答「哪些靶点值得做、哪些分子值得合成、哪些实验信息增益最大、哪些失败提示新优化方向」)
3. **必须经受实验验证** — 警惕相关性替代因果性、计算得分替代真实药效、生成新颖性替代成药性
4. **必须形成持续迭代闭环** — 「静态模型」→「动态研发体系」
5. **必须服务综合成药性** — 从单目标优化走向**多目标平衡**(活性/选择性/药代/安全性/可合成性/稳定性/临床可用性)

> *核心诘问* — 「**AI 是否真正赋能药物研发,不能只问「模型是否先进」,而要问「是否提高了研发判断质量」;不能只问「生成了多少分子」,而要问「有多少分子能够进入真实验证」;不能只问「平台设备是否高端」,而要问「数据、模型、实验和临床是否形成闭环」**。」

## 6. m4a 录音「复杂体系重塑新药研发」— AI 处理记录 

> ⚠️ **诚实声明**:AI 不能直接听音频。本节记录**已做的工作**与**缺口**。

### 6.1 文件元数据

- **大小**:34,654,2 MB
- **格式**:**MPEG-4 / DASH 分段**(ISO BMFF, `major_brand=dash`, `compatible_brands=iso6, mp41`)
- **moov 块**:offset 28,size 715 字节 — mvhd timescale `3,869,789,460`(异常高,典型 DASH),duration 44100 ticks → **常规 mvhd 时长不可信**
- **结构**:`ftyp` + `moov` + 一系列 `sidx` + `moof/mdat` 对(约 100+ 个 320KB 片段)
- **udta/meta/ilst**:offset 648,空 ilst,**无 iTunes 标题/作者元数据**
- **结论**:**不是标准录音文件,是某在线直播/录播平台导出的 DASH 分段容器**

- **首选方案**:`tiny` 模型 int8 量化 CPU 推理(快速验证可读性,后续视质量决定升档 base/small)
- **fallback**:若 DASH 直读失败,改用 ffmpeg/avconv 拼接 moof+mdat → 单 m4a 再喂 Whisper
- **限制**:本机无 ffmpeg,DASH 拼接工具链不完整 — 转写可能受阻

### 7.2 议题一(新范式) ↔ 课题叙事

- **「尺度错配」是 21 世纪医学最大难关** — 与课题「**跨尺度熵传递**(分子-细胞-器官-个体)」叙事完全同构

### 7.4 议题三(力学生物学) ↔ 课题的隐藏宝藏

**PMN 炎症网络的力学维度** — 极可能被课题**低估**的关键:

- **PMN 在血管中的力学激活**:剪切力 → PIEZO1/2 → Ca²⁺ 内流 → 趋化与 NETosis 触发(2021 诺奖背书)
- **「拥挤细胞力学微环境」(姜洪源报告主题)** — **PMN 在骨髓/血液/组织三处的力学微环境完全不同**,而当前 ODE 模型把 PMN 当均匀群体处理,**缺少力学耦合项**
- **「功能涌现:细胞集群的新行为」** — PMN 在急性炎症中形成**中性粒细胞胞外陷阱网(NETs)**+ **群集迁移(swarming)** = 涌现级动力学,**单细胞 ODE 无法刻画**
- **可能的新增头雁分子候选**:**PIEZO1/2、Myosin IIA、ICAM-1/Mac-1 力学受体簇** — 这是现有 PPARγ/SIRT3/SIRT1 主轴之外的**全新候选维度**
