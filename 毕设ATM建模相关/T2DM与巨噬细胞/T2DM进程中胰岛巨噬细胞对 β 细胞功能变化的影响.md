该文（北京中医药大学学报 2025）以中医「少火生气，壮火食气」理论为框架，系统论述 T2DM 进程中胰岛巨噬细胞对 β 细胞功能的影响：生理状态下胰岛巨噬细胞分泌 IL-10、TGF-β、IGF-1、EGF 等维持微环境稳定（少火生气）；病理状态下过度激活转向促炎（IL-1β、TNF-α、IFN-γ），经 NF-κB/氧化应激/基质重塑/血供不足四条路径驱动 β 细胞功能衰退（壮火食气）。

**核心观点与论据：**（AI 预填，供修改）
- 促炎极化（M1 样）：IL-1β/TNF-α 激活 NF-κB、增加氧化应激、诱导 β 细胞凋亡
- 氧化应激：ROS/RNS 直接损伤 β 细胞膜脂质、蛋白与线粒体，妨碍胰岛素合成分泌
- 微环境重塑：MMPs 与 TGF-β 促进胰岛纤维化，营养/氧气供应受阻
- 血供不足：血管生成因子失调 → 缺氧 → 能量供应受限 + 氧化应激加剧的恶性循环

1. **胰岛巨噬细胞的功能与“少火生气”理论**：
    
    - 在生理状态下，胰岛巨噬细胞通过分泌抗炎因子（如白细胞介素-10（IL-10）和转化生长因子-β（TGF-β））和生长因子（如胰岛素样生长因子-1（IGF-1）和表皮生长因子（EGF）），调节免疫反应，促进β细胞的增殖、存活和功能 。
        
    - 胰岛巨噬细胞通过适度的免疫调节类似“少火生气”，有助于维持胰岛微环境的稳定，保护β细胞免受过度炎症反应的损伤 。
        
2. **“壮火食气”理论及其与胰岛巨噬细胞过度活化的关联**：
    
    - 在T2DM的病理过程中，胰岛巨噬细胞的过度激活和功能失调转向促炎状态，分泌大量促炎因子（如IL-1β、TNF-α、IFN-γ），引发严重的炎症反应、氧化应激，直接损伤β细胞 。
        
    - 胰岛巨噬细胞的促炎状态类似“壮火食气”理论中的过度亢盛之火，会导致机体能量和功能的耗损 。
        
3. **胰岛巨噬细胞极化与β细胞功能障碍**：
    
    - 胰岛巨噬细胞在T2DM进程中极化为M1型（促炎型），产生如IL-1β、TNF-α等促炎细胞因子，激活NF-κB等信号通路，增加氧化应激，诱导β细胞的凋亡 。
        
    - 此外，IL-1β通过氧化应激引起β细胞膜的损伤，进而抑制胰岛素的分泌，并破坏β细胞的功能 。
        
4. **氧化应激与β细胞损伤**：
    
    - 胰岛巨噬细胞的M1型极化也导致ROS和RNS的释放，这些活性分子直接攻击β细胞，导致脂质过氧化、蛋白质损伤、线粒体功能障碍等，进一步加剧β细胞的功能衰退 。
        
    - ROS和RNS对β细胞的损伤不仅限于膜结构，还影响细胞内的信号通路，妨碍胰岛素的合成和分泌 。
        
5. **胰岛微环境的改变与β细胞功能衰退**：
    
    - 胰岛巨噬细胞通过分泌基质金属蛋白酶（MMPs）和纤维化因子（如TGF-β）促进胰岛的基质重塑和纤维化，进一步破坏胰岛的结构，妨碍β细胞的正常功能 。
        
    - 纤维化改变使得β细胞难以获得充足的营养和氧气，抑制其增殖和分化，进一步加重β细胞功能的衰退 。
        
6. **胰岛血供的不足与β细胞功能障碍**：
    
    - 胰岛巨噬细胞在T2DM进程中通过分泌血管生成抑制因子（如VEGF）影响胰岛血管生成，导致胰岛血供不足，进一步加剧β细胞的功能衰退 。
        
    - 缺氧不仅影响β细胞的能量供应，还会加剧其氧化应激反应，形成恶性循环，导致β细胞更快衰退 。
